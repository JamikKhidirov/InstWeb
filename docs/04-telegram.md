# 04. Telegram: бот и уведомления

Проект отправляет в Telegram красивое HTML-сообщение о **регистрации** и **входе**. Пароль в сообщение не попадает никогда.

---

## 1. Создать бота

1. Открыть Telegram, найти **@BotFather** (галочка верификации).
2. Отправить `/newbot`.
3. Ввести **имя** бота (видно пользователям), например `Pixora Alerts`.
4. Ввести **username**, он должен заканчиваться на `bot`, например `pixora_alerts_bot`.
5. BotFather пришлёт токен:

```
123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

Это `TELEGRAM_BOT_TOKEN`. **Никому не показывайте**: с ним можно писать от имени бота.

Полезные команды BotFather:

| Команда | Что делает |
|---|---|
| `/mybots` | список ваших ботов |
| `/setdescription` | описание бота |
| `/setuserpic` | аватар |
| `/revoke` | перевыпустить токен (если утёк) |
| `/deletebot` | удалить бота |

## 2. Узнать `chat_id`

### Личный чат (проще всего)

1. Откройте своего бота по ссылке `https://t.me/<username>` и нажмите **Start** (или напишите любое сообщение).
2. Откройте в браузере:

```
https://api.telegram.org/bot<ТОКЕН>/getUpdates
```

3. Найдите в ответе:

```json
"chat": { "id": 123456789, "first_name": "Иван", "type": "private" }
```

Число `123456789` — это `TELEGRAM_CHAT_ID`.

> Если `getUpdates` вернул `{"ok":true,"result":[]}` — боту ещё не писали, либо сообщение было давно. Напишите боту «привет» и обновите страницу.

### Группа

1. Добавьте бота в группу.
2. Сделайте его **администратором** (иначе он может не видеть сообщения).
3. Напишите в группу любое сообщение.
4. Откройте `getUpdates` — id группы будет **отрицательным**, например `-1001234567890`.

Если сообщения в группе бот не видит: у ботов включён privacy mode. Отключить: BotFather → `/setprivacy` → выбрать бота → **Disable**. После этого удалить бота из группы и добавить заново.

### Канал

1. Добавьте бота в канал как **администратора** с правом публикации.
2. `chat_id` канала: `-100...` (узнать через `getUpdates` после поста) или `@username_канала`.

### Альтернатива

Написать боту **@userinfobot** — он пришлёт ваш `id`. Для личного чата этого достаточно.

## 3. Прописать в `.env`

`server/.env`:

```env
TELEGRAM_BOT_TOKEN=123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
TELEGRAM_CHAT_ID=123456789
TELEGRAM_ENABLED=true
TZ_NAME=Europe/Moscow
```

- `TZ_NAME` — часовой пояс времени в сообщении (`Europe/Moscow`, `Asia/Almaty`, `UTC`).
- `GEOIP_ENABLED=true` — добавит город по IP (внешний сервис ip-api.com, бесплатный лимит 45 запросов/мин). По умолчанию выключено.

Перезапустить:

```bash
# локально: просто перезапустить npm run dev
sudo systemctl restart pixora-api   # на сервере
```

## 4. Проверить отправку вручную

### Linux / macOS / Git Bash

```bash
curl -s -X POST "https://api.telegram.org/bot<ТОКЕН>/sendMessage" \
  -d chat_id=<CHAT_ID> \
  -d parse_mode=HTML \
  -d text="<b>Тест Pixora</b> ✅"
```

### Windows PowerShell

```powershell
$token = "<ТОКЕН>"
$chat  = "<CHAT_ID>"
Invoke-RestMethod -Method Post `
  -Uri "https://api.telegram.org/bot$token/sendMessage" `
  -Body @{ chat_id = $chat; text = "Тест Pixora ✅"; parse_mode = "HTML" }
```

Если сообщение пришло — токен и chat_id верные.

## 6. Почему пароля нет

Это осознанное решение:

- Пароль не нужен для уведомления о событии.
- Отправка пароля в мессенджер — это утечка секрета в сторонний сервис и в историю чата.
- В коде пароль используется только для `bcrypt.compare` и нигде не логируется.

Если хочется больше контекста — включите `GEOIP_ENABLED=true`, добавьте в сообщение `User-Agent` (уже есть) или допишите поля в `server/src/telegram.js`.

## 7. Диагностика

| Симптом | Ответ Telegram | Причина | Решение |
|---|---|---|---|
| Сообщения нет, в логах `401 Unauthorized` | `401` | неверный токен | скопировать токен заново из BotFather |
| `400 Bad Request: chat not found` | `400` | неверный `chat_id` или боту не писали | нажать Start у бота, проверить id |
| `403 Forbidden: bot was blocked by the user` | `403` | бот заблокирован | разблокировать бота |
| `403 Forbidden: bot is not a member of the channel chat` | `403` | бот не добавлен в канал/группу | добавить и дать права |
| Сообщения нет, ошибок нет | — | `TELEGRAM_ENABLED=false` или пустые токен/id | проверить `.env`, перезапустить |
| Сообщение без форматирования | — | сломан HTML в тексте | не трогать `parse_mode`, экранировать `<`, `>`, `&` |
| Долгая задержка входа | — | недоступен api.telegram.org | у нас таймаут 8 с и запрос не блокирует ответ пользователю |

Посмотреть логи:

```bash
sudo journalctl -u pixora-api -n 100 --no-pager | grep -i telegram
```

Локально — просто вывод `npm run dev`.

---

## 8. Безопасность

- Токен = пароль от бота. Храните только в `server/.env` (права `600`), не коммитьте.
- Если токен попал в GitHub/скриншот — BotFather → `/revoke` → выбрать бота → получить новый.
- Для продакшена лучше отдельный бот и отдельный чат, не личный переписки.
- Не добавляйте в сообщения пароли, коды из SMS и номера карт.
